wuxiaoche

wuxiaoche is a personal assistant that runs only on its developer's own computer. It is not offered to anyone else.

It can read the developer's own Google Calendars (read-only) to answer questions like "what's on tomorrow". It can add an event to the developer's personal Google Calendar, only after the developer says yes to that event.

Privacy Policy

  • Who uses it: only its developer, on the developer's own computer, with the developer's own Google accounts.
  • Google data used:
    • "calendar.events": only to create events the developer has agreed to, on the developer's personal calendar.
    • "calendar.events.readonly": to read events from calendars the developer picked. It requests only times, status, titles, and when an event was created or last changed. It never requests attendees, locations, or descriptions.
    • "calendar.calendarlist.readonly": used only during setup, to list the developer's calendars once so the developer can pick which ones to read.
  • Storage: authorization files and calendar data stay on the developer's computer. There is no server. Nothing is collected, sold, or shared.
  • wuxiaoche's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Remove access at any time at https://myaccount.google.com/connections (choose wuxiaoche, then remove its access).
  • If the app's use of Google data changes, this page will be updated first.
