wuxiaoche

wuxiaoche is a personal assistant that runs only on its developer's own computer. It is not offered to anyone else.

It can add an event to the developer's own Google Calendar, only after the developer says yes to that event.

Privacy Policy

  • Who uses it: only its developer, on the developer's own computer.
  • Google data used: the Google Calendar permission "calendar.events", only to create events the developer has agreed to. It does not read existing calendar events.
  • Storage: the authorization file stays on the developer's computer. There is no server. Nothing is collected, sold, or shared.
  • wuxiaoche's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Remove access at any time at https://myaccount.google.com/connections (choose wuxiaoche, then remove its access).
  • If the app's use of Google data changes, this page will be updated first.
